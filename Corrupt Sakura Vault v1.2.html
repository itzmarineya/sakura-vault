Games and apps you add are saved in this browser until you publish. Publishing downloads a fresh copy of the whole site with your current library baked inside — send that file to everyone, and they'll see the update the moment they open it (including edits and deletions).

Cloud sync — every device

not configured

This is the fix for "my games aren't on the other device". The library (games, apps, and the shared Gemini key) lives in a free JSONBin.io bin. Every device pulls the newest library each time it loads the site; only an unlocked admin with the master key can push changes. The master key is stored only on your device — it is never synced, never baked into published files, so nobody else can ever get write access.

One-time setup (2 minutes)
1. Go to jsonbin.io → make a free account → copy your X-Master-Key and create an X-Access-Key (read-only).
2. Create a bin named sakura-vault-library with {"version":0,"games":[],"apps":[]} inside, set it private, copy the Bin ID.
3. Paste all three values below → Save config → Push to cloud now. Done — every device gets your library from now on.
Getting “failed to fetch”? That’s your network or an extension blocking api.jsonbin.io — never a wrong key. Press Test connection to confirm in 2 seconds.
After this, every add/edit/delete syncs automatically to all devices.
